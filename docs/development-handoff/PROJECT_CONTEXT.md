## Product Purpose

Hermes Voice is an iOS-native voice client for Ildemar's self-hosted Hermes assistant. The core outcome is hands-free conversation while driving: the app models the session as a CallKit call so iOS/CarPlay routes microphone and speaker audio through the vehicle as a system call, while the iPhone shows session status through WidgetKit and Live Activity. As of version `1.4.0`, the app also ships a native CarPlay app scene (Apple approved the `com.apple.developer.carplay-voice-based-conversation` entitlement) in addition to the CallKit-only integration.

## Current User-Facing Features

- Start/end a Hermes voice session from the app.
- Start the session through Siri/App Shortcuts using phrases such as "Falar com Hermes Voice".
- CallKit integration for mute/end controls and CarPlay call UI without a restricted CarPlay entitlement.
- Native CarPlay app scene (`CarPlaySceneDelegate` + `CPListTemplate`) with a one-tap "Diga Ei Hermes" item that starts the voice call from the CarPlay screen.
- Speech recognition with silence detection and incremental TTS playback of Hermes responses.
- HTTPS API client for `/v1/chat/completions` with streaming responses and API key storage in Keychain.
- Settings for API URL, API key, STT language, TTS speed and connection testing.
- WidgetKit extension with status widget plus Live Activity/Dynamic Island for active Hermes sessions.
- Version/changelog UI with commit link.

## Architecture

The app is generated by XcodeGen from `project.yml`.

- `HermesVoice` application target includes `Sources/` and `Shared/`.
- `HermesVoiceWidgets` app extension target includes `Widgets/` and `Shared/`.
- `VoiceSession` orchestrates CallKit, audio capture, STT, API streaming and TTS.
- `CallManager` owns CXProvider/CXCallController and is the CarPlay-compatible bridge because the app appears as a system call.
- `CarPlaySceneDelegate` (`Sources/App/CarPlaySceneDelegate.swift`) implements `CPTemplateApplicationSceneDelegate`, renders a `CPListTemplate`, and posts `.hermesCarPlayActivate` when the user taps the list item. `RootView` observes that notification and calls `session.startCall()`.
- The CarPlay scene is registered in `project.yml` under `UIApplicationSceneManifest` / `CPTemplateApplicationSceneSessionRoleApplication`, pointing at `$(PRODUCT_MODULE_NAME).CarPlaySceneDelegate`.
- `HermesAgentClient` owns the Hermes API connection and streaming response parsing.
- `HermesLiveActivityController` owns ActivityKit lifecycle updates.
- `HermesLiveActivityAttributes` is shared between the app and widget extension.
